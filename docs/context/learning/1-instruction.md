# Learning State Directory Instruction

## Responsibility

`learning-state.md` records the human's current demonstrated capability, misconceptions, assistance level, ownership stage, and next learning target. General domain knowledge belongs in `../../learning-maps/`.

## Update Contract

- Use the standard rolling-state header and increment the revision only when canonical learning evidence changes.
- Separate supplied baseline, demonstrated mastery, current assistance, misconception, and target.
- Accept evidence such as unaided explanation, accurate prediction, reconstruction, debugging, counterexamples, or transfer.
- Do not promote AI praise, fluent restatement, completed output, elapsed time, or self-confidence alone as mastery.
- Record English difficulty separately from conceptual understanding.
- Use `TBD`, `Not yet established`, or `No active item` when evidence is missing.
- Keep stable skill relationships in Learning Maps and session-specific detail in checkpoints.

## Authority

Demonstrated performance is primary. This state summarizes that evidence; Human Skills Maps provide secondary stable structure. Sidecar assessments require Mainline freshness review and human acceptance before promotion.
